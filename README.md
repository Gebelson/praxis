# PRAXIS

Site institucional da Praxis, com Vite, JavaScript, GSAP e Lenis.

## Executar localmente

```sh
npm ci
npm run dev
```

## Build e preview

```sh
npm run build
npm run preview
```

A Vercel usa `npm run build` e publica `dist/`. A navegação entre seções usa âncoras da mesma página.

## Funcionalidades

Hero com 89 frames, intro ASCII, vídeo com projeção, carrosséis, feedbacks com liquid glass, FAQ animada e formulário de orçamento.

## Formulário

O formulário atualmente registra uma confirmação local. O envio de e-mail/WhatsApp depende de uma integração de backend; esta versão não envia mensagens.

## Assets

A sequência do monitor é derivada de material de referência de Dylan Brouwer. Sua publicação requer autorização do titular. Os arquivos de análise e as versões intermediárias não fazem parte desta cópia.
